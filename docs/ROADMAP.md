# Roadmap

- Phase 0: foundation. Done in code, CI not yet run on GitHub.
- Phase 1: Windows adapter (capture, input, UIA), safe test app, global emergency stop, takeover tests on real input.
- Phase 2: local inference, capability tests, `agent-core` loop with verification.
- Phase 3: NVIDIA Nemotron adapter (`nvidia/nemotron-3.5-super-vl-120b-a12b`), consent UI, cost limits. Must be tested against the live API with a real key before being called working.
- Phase 4: Prisma and Supabase, auth, RLS, task history, full live-operation screen.
- Phase 5: security audit, signing, verified updates, packaging.
- Phase 6: macOS and Linux adapters.
